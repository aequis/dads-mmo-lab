# Playerbot Commander

Playerbot Commander is a client-side addon for WoW WotLK 3.3.5a (`Interface:
30300`) and Dad's MMO Lab's AzerothCore `mod-playerbots` server.

## Install

Copy this folder:

```text
guides/wow-wotlk/PlayerbotCommander/Client Files/Interface/AddOns/PlayerbotCommander
```

into your WotLK client:

```text
World of Warcraft 3.3.5a/Interface/AddOns/PlayerbotCommander
```

Restart the client or reload the UI, then run:

```text
/pbc
```

or:

```text
/pbots
```

## What It Covers

- Core party commands: follow, stay, summon, attack, reset, lfg, and more.
- Role, group, and class filters such as `@tank`, `@heal`, and `@group1`.
- Combat and non-combat strategies.
- Loot, item, quest, spell, talent, glyph, RTSC, raid target, pet, and tame commands.
- AddClass and altbot commands such as `.playerbots bot addclass priest`,
  `.playerbots bot init=auto Botname`, `.playerbots bot add *`, remove, list,
  and addaccount.
- Custom command box for any command not already on a button.

Command and category buttons use built-in WotLK icon textures. Hover an icon to
see the command name, exact chat command, and any required parameter. Left-click
an icon to send it. Right-click most bot-command icons to stage a macro/chat
line instead of sending it immediately.

GM commands require your character to have the appropriate server rank.
